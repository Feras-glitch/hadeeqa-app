# اختبارات المتصفح

تشغّل التطبيق في Chromium بميكروفون وكاميرا وهميين، وتلعب كما يلعب الطفل: تحلّ الألغاز والمتاهة وتمسح الغبار وتسجّل بصوتها.

```bash
pip install playwright && playwright install chromium
python3 tests/e2e_full.py && python3 tests/e2e_devices.py && python3 tests/e2e_hardening.py && python3 tests/e2e_round2.py && python3 tests/e2e_round3.py
```

| الملف | ماذا يغطي |
|---|---|
| `e2e_full.py` | المقياس الجديد (قبلي/ختامي/تذكّر، كلمات مقارنة، شفهي ثم تعرّف، إيقاف واستئناف، التصحيح الأعمى، التقرير، CSV)، ثم دلال وفرح وكريم من البداية حتى الاحتفال (بكل مفاجآت المشاهد الخمس والكلمات الإضافية)، الحديقة، الخريطة، الأصوات السحرية العشرة، السقاية، اللفافة السرية، كلمة اليوم، حكاية النوم، مسابقة العائلة، وضع ولي الأمر، الكتاب، النسخة الاحتياطية، الاختبار البعدي، لعبة الترتيب، المسرح — وأنه لا تمرير أفقي في أي شاشة |
| `e2e_devices.py` | تحدّي الإخوة بين تابلتين (فرح ← كريم ← فرح ← النجمة لكريم)، جواب بابا وماما يعود من الحاسوب دون محو تقدّم أحدث، نقل حقيبة فرح إلى جهاز جديد، رفض ملف طفل آخر، استعادة الأصوات، لعبة الكلمة المختبئة في المشاهد العشرة، ضدّ الكلمة، المسرح سطرًا بسطر |
| `e2e_hardening.py` | فحص لكل خلل وجدته المراجعة الخصمية: الإعادة لا تمسح نتيجة المحاولة الأولى، النقر بعد الحل لا يغيّر النتيجة، «التالي» أثناء إعادة التسجيل، النقر المزدوج، المؤقتات بعد مغادرة الشاشة، الرمز الإلزامي وقفله المتصاعد واسترجاعه ومستوى كل طفل، الاستعادة (ملف أقدم/تالف/مؤذٍ)، زر الرجوع في أندرويد، الخروج أثناء التسجيل، رفض الميكروفون، فشل الحفظ عند امتلاء التخزين، مغادرة الشاشة أثناء فتح الميكروفون، مؤقّت الصندوق السريع |
| `e2e_round2.py` | المراجعة الخصمية الثانية: مسجّلان معًا، تسجيل اختبار قديم لا يُحسب، اختبار ختامي موقوف يغلق الحديقة، المشهد الإضافي مشهد واحد، الشاشة القديمة لا تُرسم فوق الجديدة، رجوع مزدوج، نافذة تُغلق بزر أندرويد، ملف مصنوع، «الملف أقدم» يحسب الألعاب، نجمة تحدٍّ لكلمة لم يصلها الطفل، مستوى فرح (ج)، شاشة «اسمع» لكريم، أسئلة السقاية الجديدة وتدويرها وسقاية كريم بالصورة، عدّاد التسجيلات، معيار النجاح |
| `e2e_round3.py` | المراجعة الثالثة: الدرجات الشفهية لا تضيع عند استعادة حقيبة أحدث، التصحيح يتخطّى إجابة تسجيلها على جهاز آخر، آخر حفظ للحقيبة في التقرير، سؤال الإكمال في السقاية لا يكتب إجابته فوقه، إلغاء الرمز لا يقول «خطأ» |
| `helpers.py` | أدوات مشتركة: تمشي أي مشهد لأي مسار وتحلّ كل لعبة مفاجأة |

كل سطر ✓ فحص نجح و✗ فحص فشل؛ آخر السجل يطبع الإخفاقات وأخطاء الصفحة أو none، ويخرج برمز ١ عند أي إخفاق.
