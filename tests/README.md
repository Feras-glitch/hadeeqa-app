# اختبارات المتصفح

تشغّل التطبيق في Chromium بميكروفون وكاميرا وهميين، وتلعب كما يلعب الطفل: تحلّ الألغاز والمتاهة وتمسح الغبار وتسجّل بصوتها.

```bash
pip install playwright && playwright install chromium
python3 tests/e2e_full.py && python3 tests/e2e_devices.py
```

| الملف | ماذا يغطي |
|---|---|
| `e2e_full.py` | دلال وفرح وكريم من البداية حتى الاحتفال (بكل مفاجآت المشاهد الخمس والكلمات الإضافية)، الحديقة، الخريطة، الأصوات السحرية العشرة، السقاية، اللفافة السرية، كلمة اليوم، حكاية النوم، مسابقة العائلة، وضع ولي الأمر، الكتاب، النسخة الاحتياطية، الاختبار البعدي، لعبة الترتيب، المسرح — وأنه لا تمرير أفقي في أي شاشة |
| `e2e_devices.py` | نقل حقيبة فرح إلى جهاز جديد، رفض ملف طفل آخر، استعادة الأصوات، لعبة الكلمة المختبئة في المشاهد العشرة، ضدّ الكلمة، المسرح سطرًا بسطر |
| `helpers.py` | أدوات مشتركة: تمشي أي مشهد لأي مسار وتحلّ كل لعبة مفاجأة |

كل سطر ✓ فحص نجح و✗ فحص فشل؛ آخر السجل يطبع الإخفاقات وأخطاء الصفحة أو none، ويخرج برمز ١ عند أي إخفاق.
