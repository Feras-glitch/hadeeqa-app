# حديقة الأسرار

تطبيق قصة تعليمية بصوت الأسرة. ملف واحد `web/index.html` يحوي كل شيء.

## كيف تحصل على التطبيقات
بعد رفع المستودع إلى GitHub، يبني GitHub تلقائيًا عند كل تعديل:
- **Android APK**: Actions → آخر تشغيل → Artifacts → `Hadeeqa-android-apk`. ثبّته على الهاتف (فعّل «مصادر غير معروفة»).
- **Windows**: Artifacts → `Hadeeqa-windows` → ملف `.exe` محمول لا يحتاج تثبيتًا، وملف تثبيت.
- **نسخة ويب قابلة للتثبيت (PWA)**: Settings → Pages → Source: GitHub Actions. الرابط يعمل على أي جهاز بما فيه iPhone، ويُثبَّت من «إضافة إلى الشاشة الرئيسية».

## تحديث التطبيق
استبدل `web/index.html` بالنسخة الجديدة وارفع التغيير. يشغّل GitHub فحوص المتصفح كلها أولًا (`tests/`)، ولا يبني نسخة جديدة إن فشل فحص.
رقم النسخة يظهر في أعلى وضع ولي الأمر («🔖 النسخة») وفي كل حقيبة، فتعرف ما المثبّت على كل جهاز.

### ⚠️ قبل تثبيت أي تحديث على تابلت
1. احفظ حقيبة كل طفل وانقلها إلى الحاسوب (بالكابل).
2. ثبّت الـ APK الجديد فوق القديم **دون حذف التطبيق**.
3. إن رفض أندرويد التثبيت («التطبيق غير مثبّت» أو «تعارض في الحزمة») فلا تحذف التطبيق قبل الخطوة ١: الحذف يمحو كل بيانات الطفل على الجهاز.

السبب: الـ APK الحالي موقّع بمفتاح تطوير (debug) يصنعه GitHub من جديد في كل بناء، فقد يرفض أندرويد التحديث. يُحلّ هذا بمفتاح توقيع ثابت محفوظ في أسرار المستودع (قرار مطروح لولي الأمر).

## ملاحظة
الـ APK يصلح للأسرة ولا يصلح لمتجر Google Play. للنشر في المتجر يلزم مفتاح توقيع خاص.
